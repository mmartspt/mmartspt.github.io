# MM Arts

**Art Without Limits** · Arte contemporânea feita em Portugal

A MM Arts é uma plataforma de arte contemporânea portuguesa, fundada por **Migma (Miguel Marques)** aos 16 anos. Hoje apresenta o trabalho do seu fundador e quer crescer para dar espaço a outros artistas em Portugal.

**Site:** https://mmartspt.github.io

## O que se encontra no site

- **Coleção «Eu»** — a coleção de estreia de Migma: doze obras originais, abertas à interpretação.
- **Exposição** — a primeira exposição pública, em Oeiras.
- **Peças individuais** — obras avulsas, fora das coleções.
- **Colaborar** — para artistas, espaços e projetos que queiram trabalhar com a MM Arts.
